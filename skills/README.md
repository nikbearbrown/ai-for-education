# Educational skills

Choose a skill based on the task, not the tool. Students can use these to practice and check their work; faculty can use them to build courses, produce teaching materials, and review what students learned.

## For students

| Goal | Start with |
| --- | --- |
| Get help without having the assistant do the thinking | [Socratic Prompt Coach](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/socratic-prompt-coach) and the [AI for Students guide](https://github.com/nikbearbrown/ai-for-students-a-practitioners-guide) |
| Find evidence, check an answer, and revise academic writing | [Research](https://github.com/nikbearbrown/skills/blob/main/skills/research/SKILL.md), [Verification Before Completion](https://github.com/nikbearbrown/skills/blob/main/skills/verification-before-completion/SKILL.md), and [Graduate Writing Clinic](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/graduate-writing-clinic) |
| Prototype an app or communicate a design | [Figma Appdesigner](https://github.com/nikbearbrown/figma-appdesigner), [Figma to Godot](https://github.com/nikbearbrown/figma-to-godot), and [Figma Slides](https://github.com/nikbearbrown/figma-slides) |
| Make an explainer and document how the work changed | [Explainer Storyboard](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/explainer-storyboard), [Brutalist](https://github.com/nikbearbrown/brutalist.art), and [Frictional](https://github.com/nikbearbrown/frictional) |

Use these within your course’s AI and disclosure policy. Keep your own attempts, cite independent evidence, and be prepared to explain the result without the tool.

## For faculty

| Goal | Start with |
| --- | --- |
| Design an AI-ready course, syllabus, or assignment | [AI Readiness](https://github.com/nikbearbrown/ai-readiness), [Syllabus Architect](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/syllabus-architect), and [LLM Exercise Design](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/llm-exercise-design) |
| Make videos, lecture slides, and teaching figures | [Brutalist](https://github.com/nikbearbrown/brutalist.art), [Brutalist Slides](https://github.com/nikbearbrown/brutalist-slides), [Figma Slides](https://github.com/nikbearbrown/figma-slides), and [Figma Data Visualization](https://github.com/nikbearbrown/figma-data-visualization) |
| Review project evidence or critique a paper | [Frictional](https://github.com/nikbearbrown/frictional) and [Critique](https://github.com/nikbearbrown/critique) |
