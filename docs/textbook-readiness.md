# Textbook readiness review

A readiness result applies to a specific revision and intended use. Track reading access, course reuse clearance, agent access, pedagogical review and import verification separately. Do not award a score for evidence that was never checked.

| Check | Evidence to collect |
|---|---|
| Canonical edition | Author or maintainer designation, stable revision, audience, table of contents, full sample chapters, snapshots classified separately |
| Reuse and privacy | Explicit permission for text and bundled assets, attribution requirements and third-party exceptions; no non-release material, student records or secrets in the released source or history |
| Source structure | Navigable sequence, stable chapter/section IDs, consistent citations, resolvable links, and accessible source representations for math, figures and code |
| Teaching quality | Instructor checks level, prerequisites, outcomes, scope, worked examples, factual accuracy and at least one outcome-to-assessment mapping |
| Agent retrieval | Test authored and absent-answer questions on a frozen revision; confirm specific citations, correct edition, honest abstention, and no unauthorized retrieval |
| Course adaptation | Check an instructor can revise the course without changes to the canonical text, see provenance and inspect the exact draft before export |
| LMS import | Inspect an actual sandbox import of a versioned cartridge; compare module order, links, assets and supported assessment objects with the export manifest |

Report each check as **verified**, **needs work**, **not checked** or **not applicable**, with details. A public repository without clear reuse terms can be linked for reading; it is not an authorized source for copying into an exported course. Do not send private content to a third-party checker.

## Canonical and backup copies

Prefer the active authored source with the most complete manuscript, versioned contents, maintainers and authoritative cross-links. A course site, demo app, exported PDF, static mirror, sprint branch or archive can provide evidence without being the source of record. Link one canonical edition per work; catalog distinct volumes and editions as distinct only when the contents support it. Leave backups private and untouched. For any private canonical candidate, inspect release scope and history first. If a repository contains material not intended for publication, a reviewed public edition is safer than changing visibility of the whole history.

## Use the existing AI Readiness skill

[AI Readiness](https://github.com/nikbearbrown/ai-readiness) is the pedagogical audit. Its six questions ask whether the course has clear AI rules, requires learners to attempt the work first, gives them hands-on disciplinary AI work, teaches independent verification, records and grades process, and measures learning that AI alone cannot demonstrate. Use a human-reviewed audit with evidence from the actual course. A manuscript scan alone cannot verify course policies, graded process, accessibility in the LMS, or a learner's experience. The textbook intake checks above complement this audit; they do not replace it.
