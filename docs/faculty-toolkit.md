# Faculty skills and tools

Start with the work you need to do. These are procedures and production tools, not approvals to run student data, substitute generated evidence for human review, or install uninspected code. The [Bear Brown skill library](https://www.bearbrown.co/skills) is a broader discovery index; it distinguishes its originals and rewrites from the separately audited directory. This page covers the documented teaching, research and design uses, not every unrelated skill.

## Assess process and support research

| Skill | Useful for |
| --- | --- |
| [Frictional](https://github.com/nikbearbrown/frictional) | Audit project artifacts and process evidence separately. A commit count, log or test candidate is not proof of quality, authorship or learning; instructor judgment stays in the loop. |
| [Experiential Learning Log](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/experiential-learning-log) and [Report Evaluator](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/experiential-report-evaluator) | Structure and review co-op, internship or practicum evidence with permission. |
| [Academic Writing Coach](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/academic-writing-coach) and [Graduate Writing Clinic](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/graduate-writing-clinic) | Help faculty and students diagnose argument and evidence gaps without substituting fluent prose for research. |
| [PaperOrchestra](https://github.com/google-research/paper-orchestra) | Stage outlining, literature, sections and figures. Upstream automation has model and configuration requirements; prepare a reviewable source ledger first. |
| [Critique / CRITIQ](https://github.com/nikbearbrown/critique) and [Peer Review](https://github.com/nikbearbrown/bear-brown-tools/tree/main/skills/peer-review) | Audit research claims, methods, statistics and actual figures, and keep a revision record. These tools do not replace independent peer review. |

For a first teaching pilot, combine Syllabus Architect, AI Readiness, one explainer workflow, and Frictional. Verify the chosen artifact itself: review lesson outcomes, check captions, alt text and readings, inspect a graded exercise for independent reasoning, and test delivery in the learner view. Keep student work and private research artifacts in authorized institutional systems.
