# Build an AI-ready course with Medhavy

Medhavy is the textbook platform; its proposed MCP is the connection an instructor’s AI assistant would use to find authorized textbooks and work on an editable course draft. AI Readiness is a separate course audit tool. The aim is to let instructors start with a book, rewrite the course for their students, review it, and export a cartridge without changing the original text.

- [University textbook catalog](../catalog/): find a source and check reuse terms.
- [Medhavy and its MCP](medhavy.md): see what exists and what is being designed.
- [Course-building workflow](course-workflow.md): from a book and prompt to a reviewed course and IMSCC export.
