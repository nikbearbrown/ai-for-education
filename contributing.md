# Contributing

Useful early contributions include confirming the canonical repository for a textbook, reviewing a sample chapter against the readiness criteria, checking whether specific assets can be bundled, and testing a small Common Cartridge in an unpublished sandbox course.

Open an issue with the book or component, exact source revision, what you checked, what passed or failed, and what is still unknown. Use public source links or synthetic fixtures. Do not attach private manuscripts, student records, credentials, answer keys, or course exports from active classes. Do not assume a public link grants redistribution rights.
