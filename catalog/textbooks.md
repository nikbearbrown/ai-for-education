# University textbook catalog

Initial inventory of **42 public, chapter-based or substantial book sources**. The discovery sweep covered 756 repositories in Nik Bear Brown’s GitHub account and the Medhavy organization was reviewed separately. This list is an evidence-based first pass, not a claim that every manuscript is complete, licensed for reuse, or ready for use in class.

Each row links one recommended **public reading or source entry** for a work or distinct volume. Where duplicate names, competing editions or different reuse terms exist, the notes flag the unresolved point. Public visibility is not a redistribution license; review both text and bundled assets before making an export. Unverified, local-only, private, or backup copies are not linked here.

## Release review queue

- Confirm source-of-record and edition identity where the book body and README disagree. Some practitioner handbooks and course bundles can supplement a course without being its canonical textbook.
- Review release rights, assets and repository history for unpublished canonical manuscripts. Prefer a clean public edition if a working repo contains restricted materials. Keep backups and drafts private.
- Before adding an export-ready badge, pin input revisions, complete the faculty audit, prove scoped retrieval, and record a successful LMS sandbox import.
